A lightweight, mobile-first multi-currency asset tracker built with React Native and Expo. Tailored for volatile markets with manual exchange rate overrides and smart portfolio breakdown.

## ✨ Key Features
- **Multi-Currency Portfolio:** Unified tracking across USD, EUR, GBP, JPY, CNY, and IRT.
- **Real-Time Net Worth Calculation:** Optimized with React's `useMemo` hook to ensure high performance and fluid UI updates.
- **Dynamic Valuation & Manual Overrides:** Adapt quickly to market fluctuations by overriding official exchange rates.
- **Smart Categorization:** Organize assets into Cash, Gold, Crypto, Stocks, and more.
- **Local-First & Private:** Fast and secure persistence using `@react-native-async-storage/async-storage`.

## 🛠 Tech Stack
- **Framework:** React Native / Expo
- **Language:** JavaScript (ES6+)
- **Storage:** React Native AsyncStorage
- **Icons:** Expo Vector Icons

## 📥 Installation & Running Locally

1. Clone the repository:
   \`\`\`bash
   git clone https://github.com/Eh3an207/fintrack-ai.git
   cd fintrack-ai
   \`\`\`
2. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
3. Start the development server:
   \`\`\`bash
   npx expo start
   \`\`\`
